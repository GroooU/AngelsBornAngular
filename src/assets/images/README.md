# Изображения для Angular-приложения

В этой папке должны лежать те же файлы, что и в папке **images** оригинального HTML-сайта.

Скопируйте содержимое папки `images` из корня старого сайта в `src/assets/images/`, сохраняя структуру:

- `templates/header/` — logo.png, logo2.png, main.jpg, fon__menu-x2.jpg
- `templates/icon/` — city-icon.png, tell-icon.png, email-icon.png, favicon.ico
- `templates/` — logo3.png
- `kontakty/` — fb.png, inst.png, vk.png
- `nashi-sobaki/` — подпапки с фото собак (Nika, Alisa, Belka, Stacy, Angel, Berry, Baffi и т.д.)
- `nashe-razvedenie/` — pomet-sh, pomet-* и slider icons

После копирования перезапустите `ng serve`, если он был запущен.
